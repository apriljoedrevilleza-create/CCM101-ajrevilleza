# Laboratory 01 - Welcome to the Cloud

## Mission Overview
This lab covers onboarding to a Linux cloud environment, gathering system information, and organizing a Cloud Computing portfolio on GitHub.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
- Created a new Linux user with sudo privileges
- Gathered system information (distribution, kernel, CPU, memory, disk space)
- Built a Notes folder with a personal about-me file
- Created this GitHub portfolio repository

## Linux Commands Used
- `adduser` - create a new user
- `usermod -aG sudo` - grant sudo privileges
- `su -` - switch user
- `whoami`, `pwd`, `hostname` - identify current session
- `lsb_release -a` - check Linux distribution
- `uname -r` - check kernel version
- `lscpu` - check CPU information
- `free -h` - check memory usage
- `df -h` - check disk space
- `mkdir`, `nano`, `cat` - create and view files/folders

## Skills Learned
- Navigating a Linux terminal environment
- Managing users and permissions
- Documenting technical work using Markdown
- Structuring a professional GitHub portfolio
