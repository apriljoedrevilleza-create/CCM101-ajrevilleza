# Reflection

This laboratory activity introduced me to working inside a Linux environment and understanding how cloud engineers document and organize their work. I learned how to create and manage users, gather essential system information, and build a structured, professional GitHub portfolio.

One challenge I faced was correctly structuring folders and files in GitHub, especially getting nested folder paths right. Through trial and error, I learned how the "/" in a file path tells GitHub to create folders, and I got more comfortable using Markdown to document technical work clearly.

This activity helped me appreciate the importance of documentation and version control in real-world cloud engineering work. Moving forward, I feel more confident navigating Linux, using Git, and organizing a technical portfolio.
